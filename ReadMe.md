# MentorLM

MentorLM — коммерческий веб-сервис с ИИ-помощником для студентов российских вузов.
Продукт объединяет несколько специализированных режимов работы: общий учебный чат,
помощь с кодом и исследовательский режим с поиском по вебу.

Проект находится в активной разработке и не является open-source продуктом.

## Стек

- Frontend: Next.js, React, TypeScript, Tailwind CSS.
- Backend: Django, Django REST Framework, PostgreSQL (свой, в Docker).
- AI: OpenAI, Anthropic, потоковые ответы через SSE.
- Infra: Docker Compose, nginx.

## Структура

- `frontend/mentorlm` — веб-приложение.
- `backend/mentorlm` — API и серверная логика.
- `infra` — окружение, Docker Compose и nginx.

## Функциональность

MentorLM построен вокруг режимов — отдельных рабочих поверхностей под разные
учебные задачи, а не одного универсального чата.

- `Общий` — помощь с учебными вопросами, объяснениями, конспектами и разбором
  материалов.
- `Код` — написание, объяснение, ревью и отладка кода.
- `Исследовать` — исследовательские ответы с веб-поиском и более строгой
  структурой результата.

Внутри режимов используются сценарии: преднастроенные варианты поведения модели
для разных типов задач. Сценарий задает системную инструкцию, стиль ответа,
ожидаемую глубину, температуру, размер контекста, формат результата и доступные
инструменты. Пользователь выбирает сценарий в интерфейсе, а сервер сам собирает
итоговый промпт и параметры генерации.

В приложении есть пользовательские настройки, которые мягко влияют на поведение
ИИ: предпочтительная скорость/качество модели, стиль ответа, работа с памятью,
тема интерфейса и параметры отображения. Эти настройки не подменяют серверные
ограничения сценариев и тарифов.

Серверная часть ведет историю диалогов, потоково отдает ответы через SSE,
учитывает использование в биллинговых токенах и проверяет лимиты тарифов перед
генерацией. Для персонализации предусмотрена долговременная память: после ответа
система может извлекать устойчивые факты о пользователе и использовать их в
следующих диалогах, если это разрешено настройками.

Продуктовая часть включает лендинг, юридические страницы, страницу тарифов,
собственную авторизацию по почте и паролю и защищенные рабочие режимы приложения.
