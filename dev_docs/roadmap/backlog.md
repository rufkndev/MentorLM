# ФАЗА 3 

## идеи

- режим "модели" с раг поиском правил по построению моделей - чтобы все бизнес модели идеально строились
- Агентный режим, в котором система сама решает, как и в каком режиме лучше выполнить задачу пользователя
- мб добавить приложение оформление ГОСТ и приложение любая практика за фикс цену 
- возможность добавить к твоему аккаунту на сайте или к твоей цели тг бота - твой личный ментор + там повторение задачки и тд (типа как дуолинго?) - Бот = ежедневная карточка, напоминание об экзамене, быстрый вопрос голосом/фото
- укажи инфу по экзамену(вопросы, предмет, дата экзамена) и получи курс для подготовки(билеты, карточки, экзамен без ии, полный план подготовки с темами и тд)
